# 智能家居日志分析系统 - 前端运行指南

## 项目概述
这是一个基于React + TypeScript + Ant Design的智能家居日志分析系统前端，用于实时监控设备接口状态和离线分析接口使用情况。

## 快速开始

### 环境要求
- Node.js 16.x 或更高版本
- npm 7.x 或更高版本

### 安装依赖
```bash
# 进入项目目录
cd smart-home-analytics-frontend

# 安装依赖
npm install
```

### 启动开发服务器
```bash
npm run dev
```

### 构建生产版本
```bash
npm run build
```

### 预览生产版本
```bash
npm run preview
```

## 主要功能

### 实时监控页面
- 显示接口错误率排行榜
- 显示熔断接口列表（错误率≥5%）
- 显示正常接口列表
- 提供重置熔断状态功能

### 离线分析页面
- 显示接口使用率排行榜
- 显示建议加强优化列表（前5）
- 支持时间范围查询
- 支持触发离线分析任务

### 系统设置页面
- 配置数据刷新间隔
- 配置错误率阈值
- 配置数据保留天数
- 配置通知开关

## 后端对接

### API基础URL
开发环境：`http://localhost:8080/api`
生产环境：`/api`（通过Nginx代理）

### 主要接口
- 实时监控接口：`/realtime/*`
- 离线分析接口：`/offline/*`

详细的接口文档请参考《后端对接指南.md》

- 使用TypeScript严格模式

类型说明：

## 常见问题

### 依赖安装失败
```bash
# 清除npm缓存
npm cache clean --force

# 重新安装依赖
npm install
```

### 端口占用
```bash
# 查看端口占用
lsof -i :3000

# 杀死占用进程
kill -9 <PID>
```

### API请求失败
1. 检查后端服务是否启动
2. 检查API地址配置是否正确
3. 检查网络连接
4. 查看浏览器控制台错误信息
